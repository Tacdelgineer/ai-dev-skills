# ai-dev-skills

Small, practical Codex and Claude Skills drawn from completed development work.

- [game-3d-asset-pipeline](skills/game-3d-asset-pipeline/README.md): process GLB characters and weapons for an existing Three.js game using its current Blender helpers, animation states, and attachment system.
- [tacdel-video](skills/tacdel-video/SKILL.md): turn a coding or AI experiment into a faceless YouTube explainer: code-drawn neon risograph rooms filmed to footage, stat cards and charts from the results files, a script written to the footage, voice, CapCut edit and packaging. Carries the renderer, a starter room, a stat-card template and director-mode controls. A Claude skill: install the folder under `~/.claude/skills/`, or build the zip (`scripts/build.sh tacdel-video`, which also fails on any skill description over 1,024 characters, the claude.ai limit) and upload `dist/tacdel-video.zip` to claude.ai. Drawn from [hedgefly](https://github.com/Tacdelgineer/hedgefly); the drawing core is adapted from IshaanKalra2103's [creative-skills](https://github.com/IshaanKalra2103/creative-skills) (MIT, notice in `assets/NOTICE.txt`), and the look is inspired by Kevin Ngo's "a small light, room by room".
- [tacdel-shorts](skills/tacdel-shorts/SKILL.md): finished vertical Shorts and Reels (about 45 s) from a trend item: fact table from primary sources, a ~110-word voiceover in one take of the creator's ElevenLabs voice, code-drawn scenes timed to the words in one of four styles (riso, paper-cut, kinetic type, CRT), rendered to a 1080x1920 MP4 with voice and captions. Carries one finished example per style, a word-timing and re-timing tool, a contact-sheet checker and the renderer. A Claude skill: install like tacdel-video. The riso look shares tacdel-video's credits.
- [tacdel-motion](skills/tacdel-motion/SKILL.md): finished animated explainer Shorts (about 45 s) from just an idea, starring Tac the one-eyed robot: a story script with soul, one take of the creator's ElevenLabs voice (eleven_v4) made first so every move lands on its word, code-drawn animation in three looks (Riso 2.0, Living Simulation, Tiny AI Factory), sound effects on every action, an original code-composed score that ducks under the voice, and captions, rendered to a 1080x1920 MP4. Carries one finished episode per look, the mixer and score engine, a sound-effect library, a take checker and frame tools, and a real-terminal proof beat (VHS) for Shorts that report a real test; reuses tacdel-shorts' timing and render tools. A Claude skill: install like tacdel-video. The riso look shares tacdel-video's credits.

[FINAL_VOICE.md](FINAL_VOICE.md) is the one voice setup the three tacdel skills share (eleven_v4 only, fixed settings, one take); `scripts/build.sh` copies it into their zips. [WRAP.md](WRAP.md) is their shared end-of-video step (archive to the PC, verify the hashes, wipe the scratch), run only when the owner says "wrap <project>"; it ships in the same zips.

Each Skill has a `SKILL.md` instruction entrypoint; the Codex Skills also carry a short README with usage and provenance. Install a Codex Skill folder under `$CODEX_HOME/skills` (normally `~/.codex/skills`) to make it available in future sessions. Project code and source assets stay in their own repositories.
