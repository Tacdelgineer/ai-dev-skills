# ai-dev-skills

Small, practical Codex Skills drawn from completed development work.

- [game-3d-asset-pipeline](skills/game-3d-asset-pipeline/README.md): process GLB characters and weapons for an existing Three.js game using its current Blender helpers, animation states, and attachment system.

Each Skill has a `SKILL.md` instruction entrypoint and a short README with usage and provenance. Install the desired Skill folder under `$CODEX_HOME/skills` (normally `~/.codex/skills`) to make it available in future sessions. Project code and source assets stay in their own repositories.
